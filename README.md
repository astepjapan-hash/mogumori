# 🌿 モグもり — 食品安全チェッカー
 
食品の**商品名**や**原材料ラベルの写真**から、含まれる食品添加物を読み取り、
**デンマーク/EUの厳しい安全基準**と**四毒(砂糖・小麦・乳製品・精製植物油)**の観点で
**◎○△×** の4段階で判定するスマホ用アプリです。

> ⚠️ **大切なお願い**
> このアプリの判定は、EUの食品添加物規則(EC No 1333/2008)やデンマークの規制に関する
> 一般的な知識に基づく**参考情報**であり、**医学的な助言ではありません**。
> 最終的な判断はご自身で行ってください。

## 🚀 セットアップ手順(全体の流れ)

1. **AnthropicのAPIキーを取る**(AI判定に必要・有料)
2. **Firebaseを準備する**(履歴などをクラウド保存したい場合。省略も可)
3. **GitHubにアップして公開する**(Astepと同じ方法)
4. **スマホのホーム画面に追加する**
5. **動作確認する**

## 手順1:AnthropicのAPIキーを取得する

AI判定(写真の読み取りや添加物の判定)には、Anthropic社のAPIキーが必要です。

1. パソコンかスマホで **https://console.anthropic.com** を開く
2. メールアドレスでアカウントを作成してログインする
3. 左のメニューから **「API Keys」** を開く
4. **「Create Key」** ボタンを押し、名前(例:mogumori)を付けて作成する
5. 表示された **`sk-ant-` で始まる長い文字列**をコピーして、メモ帳などに控える
   ※この画面を閉じると二度と表示されないので必ず控えてください
6. 左のメニューの **「Billing(お支払い)」** でクレジットカードを登録し、
   クレジット(利用料の前払い。まずは **5ドル** くらいでOK)を購入する
7. アプリの **設定タブ → APIキー** に貼り付けて「保存」→「接続テスト」を押す

💰 **費用の目安**:1回の判定は数円程度です(写真判定は文字判定より少し高め)。
設定タブで「低コスト(claude-haiku)」に切り替えるとさらに安くなります。

🔒 APIキーは**スマホの中にだけ**保存され、Firebaseなど外部には保存されません。

## 手順2:Firebaseを準備する(省略も可)

> 💡 **Firebaseを設定しなくてもアプリは動きます。**
> その場合、履歴・お気に入り・NG成分は「そのスマホの中」にだけ保存されます。
> 機種変更やアプリの入れ直しでデータを引き継ぎたい場合や、
> Astepと同じようにクラウド保存したい場合はFirebaseを設定してください。

1. **https://console.firebase.google.com** を開き、Googleアカウントでログインする
2. **「プロジェクトを作成」**(または「プロジェクトを追加」)を押す
3. プロジェクト名(例:mogumori)を入力して作成する(アナリティクスは「無効」でOK)
4. 左メニューの **「構築」→「Realtime Database」** を開き、**「データベースを作成」** を押す
   - 場所は「米国」のままでOK
   - セキュリティルールはいったん **「ロックモード」** で作成
5. プロジェクトの **⚙️(歯車)→「プロジェクトの設定」** を開き、
   下の方の **「マイアプリ」→「</>(ウェブ)」** を押してアプリを登録する
6. 画面に表示される `firebaseConfig = { ... }` の中身(apiKey などの値)をコピーする
7. `index.html` をメモ帳などで開き、上の方にある
   **`const firebaseConfig = { ... }`** の「ここに貼り付け」の部分を、コピーした値に置き換える

### セキュリティルールのおすすめ設定

Realtime Database の「ルール」タブに、以下を貼り付けて「公開」を押してください。
(`/foodChecker` の場所だけ読み書きできるようにする設定です)

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "foodChecker": {
      ".read": true,
      ".write": true
    }
  }
}
```

> ⚠️ この設定は「URLを知っている人なら誰でも foodChecker のデータを読み書きできる」状態です。
> 自分だけで使う分には手軽ですが、他人にURLを教えないようにしてください。
> より安全にしたい場合は、AstepのようにFirebaseの「認証(ログイン)」機能を組み合わせる方法があります。

## 手順3:GitHubにアップして公開する

Astepと同じ流れです。

1. **https://github.com** にログインする
2. 右上の **「+」→「New repository」** を押す
3. Repository name に **`mogumori`** と入力し、**Public** のまま **「Create repository」** を押す
4. **「uploading an existing file」** のリンクを押す
5. このフォルダの中の **全ファイル**(index.html、additives.json、manifest.json、sw.js、
   icon-192.png、icon-512.png、README.md)をドラッグ&ドロップする
6. 下の **「Commit changes」** を押す
7. リポジトリの **「Settings」→ 左メニュー「Pages」** を開く
8. 「Branch」を **main** にして **「Save」** を押す
9. 数分待つと、`https://(あなたのユーザー名).github.io/mogumori/` でアプリが開けます

> 🔄 **修正したいとき**:GitHubのリポジトリでファイルを開き、鉛筆マーク(Edit)で
> 編集して「Commit changes」を押せば、数分で本番に反映されます。
> `sw.js` の一番上にある `mogumori-v1` の数字を1つ上げる(v2, v3…)と、
> みんなのスマホに新しいファイルが確実に行き渡ります。

## ❓ よくある質問

**Q. 判定は絶対に正しい?**
A. いいえ。マスタデータとAIによる**参考情報**です。特に「商品名入力」はAIの推定なので、
正確に知りたいときは原材料ラベルを撮影してください。

**Q. オフラインだと使えない?**
A. AI判定は使えませんが、テキスト入力欄に原材料名を「、」区切りで入力すると、
アプリ内のデータベースとの照合だけで簡易判定できます。

**Q. お金はどれくらいかかる?**
A. GitHub PagesとFirebaseは無料枠で十分です。かかるのはAnthropicのAPI利用料
(1判定あたり数円)だけです。

## 🌐 将来、一般公開する場合の注意(フェーズ2)

現在の作りは「使う人が自分のAPIキーを入れる」方式のため、不特定多数への公開には向きません。
一般公開する場合は、Cloudflare Workers などの無料サーバーを間に立てて、APIキーをサーバー側に
隠す「中継(プロキシ)」を作る必要があります。そうしないとAPIキーの盗用や高額請求のリスクが
あります。公開を考える段階になったら、この構成変更を先に行ってください。

## 📝 実装上の判断メモ(仕様書にない細部をどう決めたか)

- Firebase未設定でも全機能が動くよう、端末内保存(localStorage)への自動切り替えを実装(初心者が段階的に導入できるようにするため)
- 復元(データ上書き)の前に、現在のデータを自動でバックアップ書き出しする安全策を追加
- 「酵母エキス」「たん白加水分解物」は法律上は添加物ではないが、無添加志向で避けられる成分のため注意(△)扱いで収録
- 防かび剤(OPP・TBZ・イマザリル)はEUで食品添加物として未承認のため×側で判定(疑わしきは厳しめの原則)
- 一括表記(香料・調味料(アミノ酸等)など)は内容不明のため注意(△)側に倒して判定
- 乳酸・乳化剤・豆乳などは「乳」の字を含むが乳製品ではないため、四毒判定から除外する処理を実装
- AIの補完判定が通信エラー等で失敗した場合も、不明成分を「注意(△)」扱いにして判定を続行(画面が固まらないようにするため)
- 判定理由のサマリーはAIに書かせず、判定結果から自動で組み立てる方式にした(毎回同じ基準で、API費用もかからないため)
